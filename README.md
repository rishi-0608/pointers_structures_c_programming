# C Programming: Pointers and Structures

## About This Repository

This repository contains C programs created to learn and practice pointers, structures, and dynamic memory allocation in C.

## Programs Included

* `pointer_1.c` – Basics of pointers in C.
* `larger_pointers.c` – Pointer-based operations and comparisons.
* `null_pointer.c` – Understanding NULL pointers.
* `void_pointer.c` – Understanding void pointers.
* `pointers_access_using_address.c` – Accessing variables using memory addresses.
* `malloc_point.c` – Introduction to dynamic memory allocation using `malloc()`.
* `dynam_malloc.c` – Demonstration of dynamic memory allocation.
* `structures.c` – Basics of structures in C.
* `struct_stdunt.c` – Working with structures using student-related data.

## Concepts Covered

### Pointers

* Pointer declaration and initialization
* Memory addresses and dereferencing
* Accessing variables through pointers
* NULL pointers
* Void pointers

### Dynamic Memory Allocation

* Allocating memory at runtime
* Using `malloc()`
* Working with dynamically allocated memory

### Structures

* Defining structures using `struct`
* Declaring structure variables
* Accessing structure members
* Organizing related data

## How to Compile and Run

Compile a C program using GCC:

```bash
gcc pointer_1.c -o pointer_1
```

Run on Windows:

```bash
pointer_1.exe
```

Run on Linux or macOS:

```bash
./pointer_1
```

Replace `pointer_1.c` with the filename of the program you want to compile.

## Learning Objectives

* Understand pointers and memory addresses.
* Learn to manipulate data using pointers.
* Understand NULL and void pointers.
* Explore dynamic memory allocation.
* Learn to organize data using structures.
* Strengthen fundamental C programming skills.
